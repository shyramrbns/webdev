History of JavaScript

From Mocha to JavaScript.

Mocha LiveScript JavaScript

History of JavaScript

Brendan Eich created it at Netscape. It was named Mocha, then LiveScript, and became JavaScript in 1995. It is not the same as Java.

Key Names

The people and companies behind it.

Netscape Microsoft Oracle

Key Names

Netscape Navigator is where it started. Microsoft added similar scripting to Internet Explorer in 1995. Oracle bought Sun Microsystems in 2010.

Types of JavaScript

Internal and external scripts.

Internal External

Types of JavaScript

Internal goes inside the HTML file in a <script> tag. External is a separate .js file linked with <script src="script.js">.

Grid System

Bootstrap uses 12 columns per row.

12 6 4 3

Grid System

12 is full width, 6 is half, 4 is one-third and 3 is one-fourth. The sizes in a row add up to 12.

Breakpoints

Six default screen sizes.

col- col-sm- col-md- col-lg- col-xl- col-xxl-

Breakpoints

Extra small, small, medium, large, extra large and extra extra large. Each one has its own class prefix.

Cards

Row

Row

A row organizes columns horizontally. Columns always go inside a row.

Column

Holds the content inside a row.

.col-6

Column

Columns share the 12-column grid. For example, col-6 takes half of the row.
